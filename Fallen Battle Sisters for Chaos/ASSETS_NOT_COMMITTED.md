# Binary resource payload

The full test package, including the supplied mesh, animation XMLs and generated DDS textures, is provided separately as **Fallen_Battle_Sisters_for_Chaos_TestMod.zip** in the conversation.

The current GitHub connector can create UTF-8 text files but does not provide a binary attachment upload operation. Therefore this repository folder currently contains the gameplay/localization/material definitions only; the mesh, animation and DDS files are present in the downloadable ZIP and must be copied into the matching `Data/Video/` paths if you are assembling the mod from the GitHub checkout alone.

Do not substitute the obsolete `fallsister2.xml`. The ZIP uses the separately supplied `fallsister3.xml`.
